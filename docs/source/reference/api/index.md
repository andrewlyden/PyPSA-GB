# Module index

PyPSA-GB is a Snakemake workflow, not an installed package. Each rule runs one script under `scripts/`, and the
scripts share helper modules. This page lists every module with the first paragraph of its docstring, grouped by
folder. The module docstrings are the detailed method notes: open the file for the full text, the functions and
their arguments.

The tables are generated by `scripts/utilities/build_reference_tables.py --only modules`, which reads the
docstrings with Python's `ast` module and imports nothing, so the page builds without the model environment.
Re-run it after adding or renaming a module.

## Using a module outside Snakemake

Run Python from the repository root so that `scripts.*` imports resolve:

```python
import pypsa
from scripts.utilities.spatial_utils import map_sites_to_buses
from scripts.utilities.scenario_detection import is_historical_scenario

n = pypsa.Network("resources/network/Test_Market_solved.nc")
```

Most scripts run by a rule read their inputs from the `snakemake` object that Snakemake injects; many also accept
command-line arguments (`python scripts/<folder>/<module>.py --help`). Read the configuration only through
`config/config_loader.py` (`load_config`, `load_defaults`), never by loading a YAML file directly.

## Folders

| Folder | What it holds |
|---|---|
| `scripts/network_build/` | ETYS, Reduced and Zonal network builds, ETYS upgrades, branch units |
| `scripts/network_clustering/` | optional spatial clustering of the ETYS network |
| `scripts/demand/` | base demand, disaggregation (heat pumps, EVs), consumer flexibility, CP30 and FES demand builds |
| `scripts/renewables/` | weather-based renewable, marine and hydro profiles |
| `scripts/generators/` | renewable and thermal integration, marginal costs, FES and CP30 fleet builds |
| `scripts/storage/` | storage units |
| `scripts/hydrogen/` | electrolysers, hydrogen storage and turbines |
| `scripts/interconnectors/` | cross-border cables, availability and foreign prices |
| `scripts/FES/`, `scripts/CP30/`, `scripts/sources/` | NESO FES and Clean Power 2030 inputs, and the scenario-source adapters |
| `scripts/solve/` | network finalisation, the single network solve, secured boundaries and outages |
| `scripts/market/` | the two-stage market: wholesale, balancing mechanism, bids and offers, support schemes, validation |
| `scripts/consumer_bill/` | the consumer-bill accounting layer (preliminary) |
| `scripts/analysis/` | dashboards, notebooks and documentation values |
| `scripts/utilities/` | shared helpers: spatial mapping, logging, scenario detection, calendars, cutouts |
